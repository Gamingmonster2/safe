# 💼 مصروفي

تطبيق مالية شخصي عربي (RTL) لإدارة **إيرادات الإيجارات**، **مصروفات اليوم**، **المستحق غير المحصَّل**،
و**الادخار** — يعمل **أوفلاين**، يُثبَّت على الجوال كتطبيق، ويُنشر مجاناً على GitHub Pages مع دومينك الخاص.

> «المصايب كثيرة» — لذلك كل شيء بضغطة واحدة، والأرقام تُحسب تلقائياً بلا ورق ولا حسابات يدوية.

---

## 1. ما الذي يحلّه التطبيق؟

| المشكلة | الحل في التطبيق |
|---|---|
| إيجار الشهر لم أستلمه بعد ولا أتذكّر | قسم **«مستحق لي ولم يُحصَّل»** يفصل *الاستحقاق* عن *التحصيل* تلقائياً |
| مصروف الخضار والخبز والقهوة يتفلّت | **إضافة بضغطة**: أزرار جاهزة بمبالغ مقترحة |
| «كم صرفت هذا الأسبوع؟» | لوحة اليوم + التقارير + رسم بياني للرصيد |
| «وين راحت الفلوس؟» | توزيع دائري للمصروفات حسب الفئة والمكان |
| التزامات لم أسدّدها (نطاق، رسوم مدرسة) | قسم **الديون والالتزامات** — لا تُخصم من رصيدك حتى تسدّدها |
| الادخار ضعيف والتضخم شديد | مؤشر «كم شهر يكفي رصيدك» + نصيحة رقمية بلا وعظ |
| أسئلة سريعة وأنا في الشارع | **المساعد الذكي** بالصوت أو الكتابة (DeepSeek) |

## 2. التشغيل الآن (بلا إنترنت ولا تثبيت)

الأسهل: افتح `index.html` مباشرة في المتصفح — يعمل من `file://` بلا سيرفر.

أو شغّل سيرفر محلي (لتفعيل التثبيت على الجوال و Service Worker):

```powershell
cd C:\vpn\safe
python -m http.server 5173     # أو:  npx serve -l 5173
# ثم افتح: http://127.0.0.1:5173
```

> Service Worker والعمل أوفلاين يحتاجان `http(s)://` وليس `file://`. باقي التطبيق يعمل في الحالتين.

| حجرات العمال | 2,000 | شهري — أكتوبر |

**مصروفات اليوم = 302 د.ل**

| البند | المبلغ |
|---|---|
| أنبوب حديدي لتصريف مياه المطر + أجرة الصديق السوداني (100 أجرة + 20 أنبوب) | 120 |
| قهوة وسجائر وفطور | 22 |
| خضار وفواكه | 85 |
| مواد غذائية | 60 |
| خبز + ملحقات (مخبز) | 15 |

**النتيجة:** صافي اليوم **+3,098** · النقد في الصندوق **8,098** (5,000 كان موجوداً + 3,400 − 302) · الادخار **1,500** · الإجمالي **9,598**.

**لا ديون عليك إطلاقاً.** ما لم يُدفع بعد يُسمّى «مصروفات مخطّطة»، ولا يُخصم من رصيدك حتى تدفعه:

- **مصروفات مخطّطة 1,680:** بطاقة نطاق `.org` **180** (وصلت من شخص وسأسدّد عند التجديد) + كتب ابنتي **950** + الزي الجديد **450** + بنزين **100**.
- **التزام سنوي متبقٍ 5,000:** رسوم المدرسة السنوية **6,000** دُفعت منها **1,000**، والمتبقي يُسدَّد على دفعات خلال السنة (يظهر في تبويب الحسابات كمتابعة، ليس ديناً).

> الأموال في الصندوق **مجموعة من إيراداتك** — منها 5,000 كانت موجودة قبل إيرادات اليوم. التطبيق يعرض «من أين جاء النقد» في تبويب الحسابات ولوحة اليوم.

## 4. القاعدة المحاسبية الأساسية

التطبيق يفصل بين أربعة أشياء لا يخلطها Excel عادةً:

1. **الاستحقاق (Charge):** «إيجار المحل لشهر أكتوبر 1,500 مستحق عليّ تحصيله».
2. **التحصيل (Receipt):** «استلمت 1,500 اليوم» → ينشئ معاملة دخل ويسدّد الاستحقاق تلقائياً.
3. **المصروف المخطّط (Planned):** «كتب ابنتي 950 لم أشترِها بعد» → يظهر في «مصروفات مخطّطة»، **ولا يُخصم من الرصيد** حتى تضغط «دفعت».
4. **الالتزام السنوي (Commitment):** «رسوم المدرسة 6,000 في السنة، دُفعت 1,000» → متابعة فقط، ليس ديناً.

**الرصيد** = افتتاحي + الدخل المدفوع − المصروف المدفوع. ولا يُحسب فيه المخطّط.

> ⚠️ **لا يوجد «ديون» في هذا التطبيق.** أي مبلغ لم تدفعه بعد هو «مصروف مخطّط»، وليس ديناً عليك.
> النقد في الصندوق **أموال مجمّعة** من إيراداتك، لا قروض — والتطبيق يعرض تفصيل «من أين جاء النقد».

## 5. الميزات

- 🔐 **بياناتك مشفّرة ولا يراها أحد غيرك**: تسجيل دخول محلي (اسم مستخدم + كلمة سر) مع **مصادقة ثنائية TOTP**
  تعمل مع Google Authenticator / Authy / Microsoft Authenticator. التفاصيل في [docs/AUTH.md](docs/AUTH.md).
- 📅 **لوحة اليوم = اليوم فقط**: لا تختلط الأيام. اختر أي يوم من منتقي التاريخ، أو افتح «أيام فيها حركات»
  لترى الأيام السابقة وتنتقل بينها بضغطة. اليوم المختار يبقى محفوظاً في الجلسة.
- ✏️ **كل رقم قابل للتعديل**: الرصيد الافتتاحي، **تصحيح الرصيد الفعلي** (يُسجَّل الفرق كحركة تسوية واضحة)،
  الرصيد السابق في الصندوق، أرقام الالتزامات السنوية، وأي حركة (تعديل/حذف).
- 🎨 **تصميم احترافي على نمط PayPal**: أبيض + أزرق مفرح في النهاري، وكحلي عميق في الليلي.
- 🔷 **أيقونات SVG احترافية** (خط واحد، بلا إيموجي إطلاقاً) — **صفر إيموجي في التطبيق كله**، واختبار يفشل لو ظهر أي إيموجي.
- ▲▼ **مؤشرات اتجاه واضحة**: سهم صعود أخضر للدخل، وسهم هبوط برتقالي للمصروف — تعرف بنظرة واحدة من أين دخل المال وأين ذهب.
- 🌙 **وضع ليلي/نهاري** (وزر `t` للتبديل) — الافتراضي نهاري.
- 🌐 **إدارة النطاقات (نحو 150 نطاقاً)**: الأقرب انتهاءً أولاً، مع تذكيرات تصاعدية — تجديد فوري (خلال 7 أيام) · قريب (45 يوماً) · للمتابعة (90) · سقط. وزر «جدّد» يسجّل المصروف ويمدّد التاريخ سنة تلقائياً.
- 🔇 **بلا أي صوت تلقائي**: التطبيق منظومة تسجيل — النطق مُطفأ افتراضياً ولا يعمل إلا إذا فعّلته بنفسك من الإعدادات.
- 📱 **يُثبَّت على الجوال** (PWA): أندرويد Chrome ← «تثبيت التطبيق»، آيفون Safari ← «إضافة إلى الشاشة الرئيسية».
- 🔌 **يعمل أوفلاين** بعد أول زيارة.
- ⚡ **إضافة بضغطة**: خضار، مواد غذائية، خبز، قهوة، بنزين، صيانة، نطاق…
- ⏳ **تحصيل الإيجارات** بسند قبض، ويدعم التحصيل الجزئي والمتأخر.
- 💵 **الأموال المجمّعة**: تفصيل واضح «من أين جاء النقد في الصندوق» وكيف تكوّن.
- 📌 **مصروفات مخطّطة** (ليست ديوناً) تُخصم من الرصيد فقط عند دفعها، + **التزامات سنوية** للمتابعة.
- 📊 **تقارير**: مقارنة شهرية، 6 أشهر، توزيع الفئات، تنبؤ التدفق النقدي 60 يوماً.
- 🤖 **مساعد ذكي اختياري** (DeepSeek): يجيب كتابةً «كم صرفت؟» «ما الذي لم أحصّله؟» «وين راحت الفلوس؟». النطق الصوتي اختياري ومُطفأ افتراضياً.
- 💾 **تصدير/استيراد** نسخة JSON + تصدير CSV يفتح في Excel + **نسخة احتياطية مشفّرة**.

### الدخول: كيف تحمي بياناتك (بلا خادم)

الموقع ثابت على GitHub Pages، فلا يوجد سيرفر يسجّل الدخول. لذلك الحماية **تشفير حقيقي**:

| | |
|---|---|
| **أول زيارة** | شاشة إنشاء حساب: اسم مستخدم + كلمة سر (8 محارف فأكثر مع مؤشر قوة) + تلميح. المصادقة الثنائية **اختيارية ومُطفأة افتراضياً**. |
| **بعدها كل زيارة** | كلمة السر — وإن فعّلت المصادقة الثنائية، يضاف رمز من 6 أرقام من تطبيق المصادقة على هاتفك. |
| **ما يُخزَّن** | خزنة مشفّرة `AES-GCM 256` مفتاحها مشتق بـ `PBKDF2-SHA256` (310,000 دورة). كلمة السر والرمز لا يُخزَّنان. |
| **ماذا يرى الفضولي** | حروفاً عشوائية في `localStorage` — **لا رقم واحد من أرقامك**. (اختبار يفشل لو ظهر أي رقم.) |
| **زائر آخر يسجّل** | بياناته منفصلة تماماً في متصفحه — لا يرى شيئاً من بياناتك ولا تؤثر عليه. |
| **تطوير الحماية لاحقاً** | الإعدادات ← «الأمان والحماية» ← «فعّل المصادقة الثنائية» (تُعرض لك خطوات اللصق اليدوي في تطبيق المصادقة). |
| **لو نسيت كلمة السر** | لا استعادة (لا خادم). التعافي الوحيد: **ملف النسخة الاحتياطية المشفّرة** + كلمة السر. لذا صدّر نسخة بعد التسجيل. |

> **مهم:** البيانات محفوظة في متصفح هذا الجهاز. للانتقال لجهاز آخر: الإعدادات ← «نسخة مشفّرة»، ثم
> في الجهاز الجديد شاشة الدخول ← «استورد نسخة مشفّرة».

## 6. الرفع على GitHub ثم البناء

```powershell
cd C:\vpn\safe
git init
git add .
git commit -m "مصروفي — الإصدار الأول"
git branch -M main
git remote add origin https://github.com/<اسمك>/<اسم-المستودع>.git
git push -u origin main
```

ثم في GitHub: **Settings ← Pages ← Source: GitHub Actions**.
ملف `.github/workflows/deploy.yml` جاهز ويتحقق من صحة كل ملفات JS قبل النشر.

### الدومين المجاني الخاص بك
1. افتح ملف `CNAME` في جذر المشروع وضع سطراً واحداً هو دومينك بدون `https://` (مثال: `masrofi.org`).
2. في مزوّد الدومين أضف سجلاً: `CNAME` للاسم `@` أو `www` يشير إلى `<اسمك>.github.io`.
3. في GitHub Pages أضف الدومين في خانة Custom domain وفعّل **Enforce HTTPS**.

> ⚠️ **لا تضع مفتاح DeepSeek في أي ملف ترفعه للمستودع.** المفتاح يُدخل من داخل التطبيق (الإعدادات) ويُحفظ في متصفح جهازك فقط.

## 7. المساعد الذكي (اختياري تماماً)

> **التطبيق منظومة تسجيل، لا منظومة صوت.** كل الحسابات والتقارير والنطاقات تعمل **بلا مفتاح وبلا صوت**.
> المساعد إضافة اختيارية للتحليل، **ولا يصدر أي صوت إلا إذا فعّلته أنت** من الإعدادات.

1. احصل على مفتاح من [platform.deepseek.com](https://platform.deepseek.com).
2. افتح التطبيق ← **الإعدادات ← المساعد** ← الصق المفتاح ← **حفظ** ← **اختبار المفتاح**.
3. اضغط أيقونة 🤖 في الرأس واسأل بالكتابة، أو اضغط 🎤 وتكلّم (إن أردت).
4. إن أردت أن **يقرأ** المساعد ردوده بصوت عالٍ: فعّل «النطق الصوتي للردود» (مُطفأ افتراضياً).

- **بدون مفتاح:** يعمل محرّك محلي بالكامل أوفلاين ويجيب على أسئلة الأرقام («كم صرفت اليوم؟»).
- **مع مفتاح:** تحليل أعمق، ملخصات مكتوبة، وتوصيات.
- المفتاح يبقى على جهازك؛ الاستدعاء يذهب مباشرة إلى `api.deepseek.com` ولا يمرّ بأي سيرفر وسيط.

> ملاحظة: تبويبات الشريط السفلي سبعة (اليوم، المصروفات، الإيرادات، الحسابات، التقارير، النطاقات، الإعدادات).
> المساعد في أيقونة 🤖 بالأعلى لأنه إضافة اختيارية لا تبويب أساسي.

## 10. نسخ احتياطي (مهم)

بياناتك في **متصفح هذا الجهاز فقط**. لذلك:
- الإعدادات ← **تصدير نسخة (JSON)** كل أسبوع، واحفظها في Drive أو بريدك.
- عند تغيير الجهاز: **استيراد نسخة**.

> المرحلة التالية (اختيارية): مزامنة تلقائية إلى Google Sheets أو Supabase حتى لا تعتمد على نسخة واحدة.
