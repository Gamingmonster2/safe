# أيقونات «مصروفي»

كل الأيقونات **مولَّدة آلياً** بملف واحد بلا أي مكتبة خارجية:
`node tools/make-icons.mjs` — يكتب PNG حقيقياً (توقيع + IHDR + IDAT بـ `zlib` + IEND مع CRC32 محسوب يدوياً)
بنوع لون 6 (RGBA، 8 بت)، ويستطيع توليد أيقونة `maskable` يرسم محتواها داخل 80% المركزية.

التصميم واحد في كل المقاسات: مربع بخلفية متدرّجة من `#2f6df6` إلى `#0b1020`،
وفي الوسط محفظة بيضاء وفيها **دينار ذهبي** وإبزيم أزرق — يبقى مقروءاً حتى في 32 بكسل.

## جدول الأيقونات

| الملف | المقاس | الاستخدام | الشفافية |
|---|---|---|---|
| `icon-192.png` | 192×192 | `manifest` → `purpose: "any"` (أندرويد/سطح المكتب) | زوايا دائرية شفافة |
| `icon-512.png` | 512×512 | `manifest` → `purpose: "any"` (شاشة البداية، متجر) | زوايا دائرية شفافة |
| `icon-maskable-192.png` | 192×192 | `manifest` → `purpose: "maskable"` (أندرويد يقصّها بأي شكل) | معتمة بالكامل |
| `icon-maskable-512.png` | 512×512 | `manifest` → `purpose: "maskable"` | معتمة بالكامل |
| `apple-touch-icon.png` | 180×180 | أيقونة آيفون/iPad (Safari يقرأها من `<link rel="apple-touch-icon">`) | معتمة بالكامل (iOS يرفض الشفافية) |
| `favicon-32.png` | 32×32 | أيقونة تبويب المتصفح | زوايا دائرية شفافة |
| `favicon.ico` | 32×32 | حاوية ICO فيها PNG 32×32 (`ICONDIR` + `ICONDIRENTRY` + بيانات PNG) | زوايا دائرية شفافة |

> المنطق: `maskable` يحتاج خلفية تصل إلى كل الحواف (لأن أندرويد يقصّ الأيقونة دائرة/مربعاً مستديراً)،
> لذلك رسمها موضوع داخل 80% المركزية حتى لا يُقطع الدينار ولا المحفظة. أما أيقونة آيفون فبلا شفافية إطلاقاً
> لأن iOS يضع خلفيته السوداء مكان الشفافية.

## إعادة التوليد

```bash
node tools/make-icons.mjs
```

- السكربت **idempotent**: المخرجات ثابتة بايت-بايت (لا وقت ولا عشوائية)، فإعادة تشغيله لا تُنتج اختلافاً.
- لا يحتاج `npm install` ولا أي حزمة — يستخدم `node:zlib` المدمج فقط (اختُبر على node v24).
- بعد التعديل على الرسم: شغّله ثم تحقق بـ `node tests/_pwa.check.mjs`
  (يفحص توقيع PNG، أبعاد IHDR بايت-بايت، CRC32 لكل مقطع، فكّ IDAT، وأن الأيقونات ليست فارغة).
- لو غيّرت الأسماء أو المقاسات: حدّث `manifest.webmanifest` **و** قائمة `PRECACHE` في `sw.js` معاً.

## تثبيت التطبيق على الجوال

**أندرويد (Chrome / Edge):**
1. افتح رابط الموقع (مثال: `https://<user>.github.io/<repo>/`).
2. انتظر ثانية حتى يكتمل التخزين المسبق للـ Service Worker.
3. القائمة (⋮) ← **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
4. ستظهر أيقونة «مصروفي» مع المحفظة والدينار الذهبي، ويفتح التطبيق بلا شريط عنوان.

**آيفون / آيباد (Safari — إلزامي Safari وليس Chrome):**
1. افتح الرابط في **Safari**.
2. زر **مشاركة** ⬆️ ← **«إضافة إلى الشاشة الرئيسية»** ← إضافة.
3. ستُستخدم `apple-touch-icon.png` تلقائياً.

## أوفلاين

- بعد أول زيارة واحدة ناجحة، يقوم `sw.js` بتخزين هيكل التطبيق وكل ملفاته مسبقاً.
- بعدها يعمل التطبيق **بلا إنترنت** (الشاشات، الحسابات، الإدخال، التقارير) لأن كل شيء محلي في `localStorage`.
- الوكيل الذكي وحده يحتاج إنترنت (اتصال `api.deepseek.com`)، وهو لا يُخزَّن في الكاش أبداً.
- عند نشر إصدار جديد: غيّر `C.VERSION` في `assets/js/constants.js` واسم `CACHE` في `sw.js` معاً،
  فيُحدَّث التطبيق عند المستخدم فوراً (network-first للهيكل).
